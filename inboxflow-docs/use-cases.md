# Supported Use Cases

## 1. Tech Recruiter Flow
- Extracts pay rate, remote status, and job details.
- Auto-generates responses (accept, negotiate, request more details).

## 2. Real Estate Wholesaling Flow
- Processes property inquiry emails, extracts details.
- Generates follow-ups or offer messages.

## 3. Customer Service Flow
- Classifies and auto-responds to customer inquiries.
- Escalates complex cases.

## 4. Contracting Jobs Flow
- Handles incoming project inquiries and RFPs.
- Generates pricing estimates and follow-ups.
